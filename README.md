# AI Interview Prep Platform 🎯

An AI-powered mock interview platform that generates role-specific 
interview questions, evaluates your answers in real time, and gives 
a detailed performance report.

## Features

- 🎭 6 role types — Frontend, Backend, Full Stack, ML, Data Science, DevOps
- 🤖 AI-generated questions tailored to your role and level
- 📝 Real-time answer evaluation with score and feedback
- 💡 Hints available if you get stuck
- ✅ Strengths and improvement areas for each answer
- 💡 Ideal answer shown after each question
- 📊 Final report with hire recommendation
- 📚 Study topics suggested based on performance

## Tech Stack

- **Python** + **Flask** (backend)
- **Groq AI** + **LLaMA 3.3** (question generation & evaluation)
- **HTML/CSS/JavaScript** (frontend)

## Run Locally

1. Clone the repo
```bash
   git clone https://github.com/Anchal2000-hue/interview-prep.git
   cd interview-prep
```

2. Install dependencies
```bash
   pip install flask groq python-dotenv
```

3. Create `.env` file
4. Run the app
```bash
   python app.py
```

5. Open http://127.0.0.1:5000

## How It Works

1. Select your target role and experience level
2. Choose number of questions (5, 10, or 15)
3. Answer AI-generated interview questions
4. Get instant feedback with score, strengths, and improvements
5. View your final report with hire recommendation

## Supported Roles

| Role | Focus Areas |
|------|-------------|
| Frontend Developer | React, JavaScript, CSS, Performance |
| Backend Developer | APIs, Databases, System Design |
| Full Stack Developer | End-to-end development |
